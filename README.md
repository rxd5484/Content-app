# AI Content Assistant

AI Content Assistant is a full-stack AI-powered web application that helps users quickly generate structured content such as blog posts, social media content, marketing copy, and more.

Users can choose a content type, enter a topic, select a tone, provide optional keywords, and generate ready-to-edit content using OpenAI's GPT models.

## Features

* AI-powered content generation
* Blog post generation
* Social media and marketing content
* Multiple tone options
* Optional keyword targeting
* Markdown-formatted output
* Content editing after generation
* Custom NLP fallback logic
* Free and Pro subscription plans
* SEO-focused generation features for Pro users
* User authentication
* Profile and account management
* Subscription and billing pages
* Content generation dashboard
* Recent content history
* Daily generation limits

## Tech Stack

### Frontend

* Next.js 14
* React
* Tailwind CSS

### Backend

* Next.js serverless API routes
* OpenAI Node SDK
* GPT models

### Deployment

* Vercel

## How It Works

The user provides a few simple inputs:

1. Select a content type
2. Enter a topic
3. Choose a tone
4. Add optional keywords
5. Generate the content

The application sends the request to the backend, where the prompt is processed and sent to the OpenAI API.

The generated response is then displayed in a structured format that the user can edit or use directly.

### Example

Input:

```text
Content Type: Blog Post
Topic: Marketing in Valorant
Tone: Informative
```

The application can generate a structured article containing:

* A title and introduction
* Organized sections
* Relevant subheadings
* Bullet points
* A conclusion
* Formatting suitable for web publishing

## Content Customization

Users can control the output using different generation parameters.

### Content Type

Choose the type of content you want to create.

Examples include:

* Blog posts
* Social media content
* Marketing copy
* Emails

### Tone

The generated content can be adapted to different tones, such as:

* Informative
* Enthusiastic
* Professional
* Casual

### Keywords

Users can optionally provide keywords to help guide the generated content toward a specific topic or audience.

## Free and Pro Plans

The application supports different subscription levels.

### Free

Provides access to the core AI content generation features with generation limits.

### Pro

Includes additional generation capabilities and SEO-targeted content formatting.

## User Dashboard

The dashboard gives users an overview of their account and generated content.

Users can view:

* Total content generated
* Remaining generations
* Current subscription plan
* Recently generated content
* Creation dates
* Previous content for editing

## Account Management

Users can manage their account through the profile section.

Available functionality includes:

* Updating name and email
* Updating password
* Viewing the current subscription plan
* Viewing upgrade options
* Managing billing information
* Viewing billing history

## Authentication

The application includes a sign-in and registration interface that allows users to access their account using their email and password.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rxd5484/Content-app.git
cd Content-app
```

Install the dependencies:

```bash
npm install
```

Configure the OpenAI credentials required by the application.

Then start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

in your browser.

## Deployment

The application is designed to be deployed using Vercel.

After connecting the repository to Vercel, configure the required environment variables and deploy the application.

## Why This Project?

Writing content from scratch can be time-consuming.

AI Content Assistant simplifies the process by turning a small amount of user input into structured content that can immediately be reviewed, edited, and published.

The project also demonstrates how generative AI can be integrated into a modern full-stack web application using Next.js, serverless APIs, and OpenAI.
